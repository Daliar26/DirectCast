# DirectCast 0.1.0 — experimental MVP

Проект Android-приложения для локальной передачи экрана по Wi‑Fi hotspot.

## Устройства
- Телефон: Redmi 12 (режим Sender)
- Проектор: Android A10 (режим Receiver)

## Запуск
1. Соберите APK через Android Studio или GitHub Actions.
2. Установите один и тот же APK на оба устройства.
3. Включите точку доступа на Redmi 12 и подключите к ней проектор.
4. На проекторе откройте DirectCast → «Приёмник» → «Начать приём».
5. Посмотрите IP проектора в приложении.
6. На телефоне откройте DirectCast → «Передатчик», введите IP проектора и нажмите «Начать трансляцию экрана».
7. Разрешите Android захват экрана.

## Важные ограничения версии 0.1
Это ранний сетевой прототип, а не готовая стабильная система:
- используется UDP без фрагментации/повторной сборки кадров; большие кадры могут теряться;
- звук пока не реализован;
- передача отдельных видеофайлов пока не реализована;
- адрес проектора вводится вручную;
- Android 14+ может требовать foreground service для MediaProjection — в следующем этапе добавим полноценный сервис;
- совместимость аппаратного декодера A10 необходимо проверить на устройстве.

Цель этой версии — проверить установку, доступность локальной сети и базовую совместимость H.264. Не использовать для оценки итогового качества.
